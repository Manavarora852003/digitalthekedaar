Production checklist

  • Change default admin credentials.
  • Set a long random JWT_SECRET.
  • Use HTTPS on deployment.
  • Use persistent storage for SQLite or move to PostgreSQL.
  • Connect Razorpay/Stripe for live payments.
  • Connect SMS/WhatsApp provider for OTP and notifications.
  • Configure backups, monitoring and domain email.
